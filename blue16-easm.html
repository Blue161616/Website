1 Authentication

Add a Single-page application platform with redirect URI

  • It must be the SPA platform, not Web — a Web registration rejects the token exchange with a cross-origin redemption error.
  • MSAL cannot use file://; serve the file over http(s).

2 API permissions

APIs my organization uses → all Delegated, none needing admin consent

  • EASM APIAssetResource.Read.All assets + observations
  • EASM APIWorkspace.Read.All workspace metadata
  • Azure Service Managementuser_impersonation discovering which workspaces exist
  • Azure Cognitive Servicesuser_impersonation only for the Azure OpenAI recommendation provider

Microsoft Graph's openid, profile, User.Read and offline_access are MSAL defaults — keep them. offline_access is what supplies the refresh token that keeps silent renewal working without a hidden iframe.

3 Azure access

Delegated tokens act as the signed-in user, so each user needs their own role assignment — API permissions alone grant nothing here.

  • Assets — a role on the Microsoft.Easm/workspaces resource. Microsoft documents Contributor.
  • Coverage gap, Azure side — Reader on each subscription whose public IPs should be compared. No extra API permission: Azure Service Management already covers the call. A subscription you cannot read is skipped silently, which looks like a clean result rather than a missing one.
4 Defender devices

Nothing to grant. Defender's APIs send no CORS headers, so a browser cannot call them whatever permissions the app registration holds — that is why the internet-facing device list is imported on the Coverage gap tab. Whoever runs the export needs advanced-hunting access in Defender; this app registration is not involved.
