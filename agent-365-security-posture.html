  • ID Protection for Agents is enabled — agent sign-in / identity risk is detected and feeds risk-based policy

Threat protection · runtime

Microsoft Defender — findings & remediation

Runtime threat signals for agents. Defender's detections aren't exposed to a read-only Graph app, so the checks below flag Graph-visible runtime risk (Microsoft-disabled, dormant) alongside the Defender controls to verify in-portal.
Agent 365 · Defender controls to confirm in-portal
  • Agent 365 data source enabled — unified agent visibility & AI-threat detection
  • Microsoft 365 connector connected with Entra ID management events + Microsoft 365 activities (investigation & advanced hunting)
  • Copilot Studio connector connected — runtime monitoring for suspicious behavior / cross-prompt-injection
  • Real-time protection policy active · Prompt evidence collection configured
  • Hunt agent activity via the AgentsInfo advanced-hunting table (KQL)
  • No open XDR incident implicates an agent identity
