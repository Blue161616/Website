  • Agent 365 data source enabled — unified agent visibility & AI-threat detection

Agent identities

Each row is one agent identity, risk-scored 0-100 from its permissions, roles, ownership, blueprint credential hygiene and Microsoft-disabled status. Permissions include both grants on the agent's own service principal and permissions inherited from its blueprint (shown in the portal as Grant source = “Inherited”) — the agent SP looks empty but still holds them. The blueprint is the security boundary — it holds the credentials and impersonates its agents, so a blueprint compromise affects every agent under it. Click a row for the breakdown.

Tools & MCP servers

The agent action surface — the tools, MCP servers and connectors agents can invoke to reach data and external code. This is where an agent's real reach lives (beyond its Entra permissions). Read live from the Defender AgentsInfo table; grant ThreatHunting.Read.All to populate it.
