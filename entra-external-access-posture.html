API permissions

Microsoft Graph → all Delegated. Every one is read-only.

Microsoft GraphPolicy.Read.All the cross-tenant access policy — required
Microsoft GraphCrossTenantInformation.ReadBasic.All resolve partner tenant IDs to names — required
Microsoft GraphUser.Read.All correlate guests to partner tenants optional

Without the third the report still runs; the guest correlation section reports itself unevaluated rather than showing zero guests.

3
Admin consent

All three require it. Adding the permissions is not the same as consenting to them — a Global Administrator has to consent tenant-wide before any call returns data. The Grant admin consent button above opens that screen.

4
What this reads, and what it does not

Only the cross-tenant access policy as Graph returns it: the default configuration, the per-partner overrides, and cross-tenant synchronisation. Nothing is written.

  • It does not simulate sign-in. There is no effective-access evaluation here, so nothing is claimed about what a given external user would be permitted at runtime.
  • A partner setting of null is reported as inherited, never as blocked — inherited from a permissive default is permissive.
  • Tenants with no partner entry are governed entirely by the default, which is why the default is reported first and in full.
