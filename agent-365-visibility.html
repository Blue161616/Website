Which agents can each screen see?

Four Microsoft surfaces count the AI agents in your tenant, and they return four different numbers. None of them is wrong — each counts a different kind of object, and each is blind to something. Sign in and this reads all four from your own tenant, lines them up against the platforms your agents were built with, and explains every gap. Read-only throughout; nothing is written or changed.

Connect to your tenant

You need an app registration in your own tenant — a Single-page application with redirect URI set to the address this page is served from (). Grant the delegated permissions below; every one is optional and the matrix simply marks a column unavailable if you skip it.

AgentIdentity.Read.All
Entra agent identities — the agents your identity controls can actually reach.
ThreatHunting.Read.All
The AgentsInfo table: everything Defender sees running, including agents installed on endpoints. Needs a Security Reader-style role.
CopilotPackages.Read.All
The Agent 365 registry (catalogue titles). Needs the AI Administrator or Global Administrator role.
