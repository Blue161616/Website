    Create it with a script

    PowerShell 7 + the Microsoft.Graph module (Install-Module Microsoft.Graph), signed in as a Global Administrator. It creates the SPA app, adds this page's redirect URI, requests every permission in Permissions this app needs above and grants admin consent, then prints the Client ID and Tenant ID. Scope IDs resolve by name at runtime, so it never goes stale.
