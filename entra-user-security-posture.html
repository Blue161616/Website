1
App registration

Register this page's URL as a Single-page application redirect URI:

  • It must be the SPA platform, not Web — a Web registration rejects the token exchange with a cross-origin redemption error.
  • MSAL cannot use file://; serve the page over http(s).
2
Required permissions

Microsoft Graph → Delegated, read-only, admin consent

Directory.Read.All users, groups, licences
RoleManagement.Read.All directory role assignments — who is privileged
Application.Read.All service principals behind role holders
User.Read sign-in

Nothing here writes. These four are the floor — without them the scan cannot start.

3
Optional permissions — each degrades gracefully

Absent ones are reported as not assessed rather than as a clean result.

AuditLog.Read.All per-user MFA-method posture + last-sign-in staleness
Policy.Read.All whether each admin is actually covered by an enforcing MFA Conditional Access policy
IdentityRiskyUser.Read.All Entra ID Protection risk (P2)
RoleManagementPolicy.Read.Directory which eligible roles require approval to activate — lowers the score for approval-gated eligibility
roleEligibilityScheduleInstances PIM eligibility, via the scopes above — needs P2

The last is an API rather than a scope: it is read with the role permissions already granted, and returns nothing without a P2 licence.

4
Directory role

Delegated tokens act as the signed-in user, so the permissions above grant nothing on their own — the account needs its own read access.

  • Global Reader is enough for everything on this page, and grants no write anywhere in the tenant.
  • Without it the scan returns few or no users, which looks like a small tenant rather than a blocked read.

Highest-risk combination ?Why this compound: privilege is only as strong as the credential in front of it, and only as contained as the gate in front of that. A permanent write role means there is no activation step to notice or approve; Tier-0 means the role is GA-class; weak or no MFA means the credential is phishable. Together that is one phish away from the top of the directory.
