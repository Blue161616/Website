# Secure AI Explained

An interactive explainer of Microsoft's **Secure AI** announcement of
19 October 2026: securing AI agents as the new insider risk, at speed and
scale. It is written for management and security engineers at once and runs
entirely in the browser as static content, with no sign-in and no tenant
connection.

- **File:** `secure-ai-explainer.html`
- **Category:** Security Operations
- **Status:** Explainer (based on preview information, subject to change)

---

## What it does

A **Management / Both / Technical** switch at the top changes the opening text,
pros and cons and the checklist for whoever is reading.

- **Multi-layer containment:** identity, permissions, data, endpoint, network,
  cloud and runtime, with the model layer marked as in development.
- **Why it exists:** an animated before/after of the agent acting as the
  employee versus the agent as a distinct actor with its own Agent ID.
- **Know · Protect · Adapt:** the three outcomes as one continuous loop.
- **Discover and identify:** a discovery radar for local and cloud agents, the
  four Agent ID types and the agent identity lifecycle.
- **Dynamic agent risk simulator:** sensors feed the context engine; step
  through an expense-agent scenario and watch Dynamic Conditional Access
  respond in stages, from allow to block.
- **Dynamic Permissions:** the agent starts at zero and gets task-scoped,
  time-bound access, human approval or a denial, with a decision log.
- **Containment demo:** requests from a local agent stopped by Defender,
  Windows MXC, Entra GSA or Purview DLP.
- **Project Perception:** red, blue and green agent teams, Guardian agents and
  a replayable playbook session.
- **Roadmap, preview-fit check, pros/cons/watch-outs, quiz, next-steps
  checklist and resources.**
