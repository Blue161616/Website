# Project Perception Explained

An interactive explainer of **Project Perception**, Microsoft's agentic security
system in Microsoft Defender (preview). It runs entirely in the browser as static
content, with no sign-in and no tenant connection, and is the companion to the
ISOC explainer (`isoc-explainer.html`).

- **File:** `perception-explainer.html`
- **Category:** Security Operations
- **Status:** Explainer (based on public preview documentation, subject to change)

---

## What it does

A **Management / Both / Technical** switch at the top tailors the text, pros and
cons and checklists to the reader.

- **The agent team:** an animated constellation of the six Microsoft-published
  agents around the harness: Recon (red); Threat Intelligence, Triage, Attack
  Investigation and Detection Authoring (blue); Posture Prioritization (green).
- **What it is:** "AI that acts" (Perception) versus "AI that assists"
  (Security Copilot), and the layers: cyber models, harness, agents, the ISOC
  foundation, consumption pricing and preview status.
- **Agent relay:** an illustrative playbook where each agent's output feeds the
  next.
- **Ways to work:** animated mock-ups of chat, agents and playbooks.
- **Session simulator:** watch an Attack Investigation session, then approve,
  reject or suggest an alternative, with the session status board updating.
- **Identity and access:** new Entra Agent ID versus an existing user account,
  with a diagram of what the agent can reach; Security Admin vs Security Reader;
  the URBAC prerequisite.
- **Getting started, pros/cons/watch-outs, quiz and resources** (Microsoft product
  page and Learn documentation).
