# Microsoft Agent 365 — The Control Plane for Agents

An interactive explainer that lays out how Microsoft Agent 365 treats every AI
agent like a member of the workforce — given identity, access, oversight and
defense. It maps the builders, the three security pillars and the engines behind
them, and decodes the product vocabulary you will hear. It runs entirely in the
browser as static content — there is no sign-in and nothing is read from a
tenant.

- **File:** `microsoft-agent-365-control-plane.html`
- **Category:** Agent 365
- **Status:** Explainer

---

## What it does

Walks through the Agent 365 model as a single, clickable page:

- **The big idea** — why Microsoft frames agents as a workforce that needs
  identity, access, oversight and defense, stated up front in one paragraph.
- **The control plane, mapped** — an interactive diagram whose nodes you can
  click, including the builders that produce agents: **Agent Builder** (no-code),
  **Copilot Studio** (low-code) and **Microsoft Foundry** (pro-code), and how
  they interoperate.
- **Microsoft's three pillars** — the **Observe · Govern · Secure** framing.
- **The three engines, up close** — a tabbed view of the underlying products
  (Entra, Defender, Purview) and the role each plays.
- **Five capabilities you'll hear named** — the product vocabulary, decoded.
- **An agent's lifecycle** — from create to retire, traced through the control
  plane.
- **Key terms, decoded** — a glossary of the Agent 365 language.

It also surfaces the headline facts it teaches: GA on **May 1, 2026** with
enforcement from **July 1, 2026**; per-user licensing (Microsoft 365 E5 + Agent
365, or Microsoft 365 E7); the admin home in the Microsoft 365 admin center.

---

## Requirements

**No sign-in required.** It runs entirely in the browser and is pure static
content — nothing is fetched from your tenant, and no app registration, token or
permission is involved.

---

## How to run

1. Open the page over http(s) (e.g. via `blue16.nl`, GitHub Pages, or any static
   host).
2. Read top to bottom, or click the control-plane nodes, engine tabs and diagram
   elements to expand each part.

There is no tenant connection and no demo mode toggle — the whole page is the
explainer.

---

## Privacy & safety

- **Nothing is collected or sent.** The page is static content rendered locally;
  there is no backend, no authentication and no network calls to a tenant.
- Safe to open anywhere — it neither reads nor writes anything in Microsoft 365.

---

## Limitations

- It is an **explainer, not a scanner** — it describes how Agent 365 works and
  does not inspect, score or report on any real tenant.
- Product facts (GA dates, licensing, capability names) reflect Microsoft's
  announced model at the time of writing and may drift as the product evolves.
