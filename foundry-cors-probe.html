Foundry Agents CORS / Auth Probe

Throwaway diagnostic: can a browser-only SPA read the Azure AI Foundry Agent data plane directly? It acquires (or accepts) an https://ai.azure.com token and does a single GET {endpoint}/agents. If the response is readable → CORS is OK and a full Foundry inventory tab is feasible. If the fetch is blocked → the data plane doesn't allow browser origins, and it'd need a backend/proxy.
