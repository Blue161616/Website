Optional — full environment list: add Power Platform API (8578e004-a5c6-46e7-913e-12f58912df43) → EnvironmentManagement.Environments.Read (delegated), grant admin consent, and hold the Power Platform Administrator / Global Admin role.
Tenant DLP is not readable from this page — and no role fixes that. DLP lives only on the legacy admin API (api.bap.microsoft.com), which custom app registrations can't be granted delegated access to (it isn't in the API picker; the Power Platform API has no DLP permission), and browsers block it via CORS. Being Global Admin grants the authorisation but not the token. So the baseline below is computed excluding DLP gaps and may read better than reality — review DLP in the Power Platform admin center, or via Get-DlpPolicy (Microsoft.PowerApps.Administration.PowerShell).
Coverage is limited to environments where your account has a Dataverse security role.
