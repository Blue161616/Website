1
App registration

Register this page's URL as a Single-page application redirect URI:

  • It must be the SPA platform, not Web — a Web registration rejects the token exchange with a cross-origin redemption error.
  • MSAL cannot use file://; serve the page over http(s).
2
Required permissions

Microsoft Graph → Delegated, admin consent

AgentIdentityBlueprint.Read.All blueprints in this tenant
AgentIdentity.Read.All the agent identities created from them
AgentIdentityBlueprintPrincipal.Read.All blueprints present in the tenant, including externally-owned ones
Application.Read.All resolves permission-scope GUIDs to names, and reads app-role assignments
DelegatedPermissionGrant.Read.All delegated consent on the blueprint principal
CrossTenantInformation.ReadBasic.All resolves an external blueprint's owner tenant to its org name and domain
User.Read sign-in

These seven are the floor — without them the scan cannot start.

3
Optional permissions — each degrades gracefully

Absent ones are reported as not assessed rather than as a clean result.

AuditLog.Read.All per-agent sign-in and dormancy
IdentityRiskyAgent.Read.All risk state — falls back to IdentityRiskyServicePrincipal.Read.All
Policy.Read.All Conditional Access coverage

Risk state and Conditional Access for workload identities both need Workload ID Premium; without the licence the scopes are granted but return nothing, which the page reports as hidden rather than as clean.

4
Delete — asked for only when you delete

This is the one tool in the suite that can change something. Neither scope is part of sign-in, so an auditor can run the whole scan without holding delete rights.

AgentIdentityBlueprint.DeleteRestore.All delete a blueprint — cascades to the agents created from it
AgentIdentity.DeleteRestore.All delete a single agent identity

Both are DeleteRestore, which needs only the Agent ID Administrator role — not Cloud Application Administrator. The generic /applications delete would have required Cloud App Admin, which most Agent ID admins do not hold, and returned 403.

5
Directory role

Delegated tokens act as the signed-in user, so the permissions above grant nothing on their own — the account needs its own read access.

  • Global Reader covers everything the scan reads, and grants no write anywhere.
  • Deleting additionally needs Agent ID Administrator.

Highest-risk combination ?Why this compound: a blueprint’s own grants are inert — what matters is the fleet it can mint and what those agents inherit. So the chain starts at blast radius (does it have agents at all), adds whether its granted permissions actually reach them through the inheritable conduit, then the two escalators: a client secret is a copyable key that impersonates the whole fleet, and multi-tenancy means the blueprint is reachable from other tenants.

How to read it: left to right as one AND. The big number is how many blueprints carry that factor and every factor before it, so it can only fall; the small number is how many carry that factor anywhere in the estate.
