Blue16 Sightline light ● Passive · sends no traffic to the estate

1Defender device export

Defender portal → Hunting → Advanced hunting → paste the query → Run → Export. A role that can run hunting queries is enough — no app registration, no consent. This is the only route that carries a public IP; the Devices blade export does not.

Deliberately not filtered on IsInternetFacing: a filtered device list turns “not in this file” into a coverage gap that does not exist, and the report flags it when every row is internet-facing.

2Azure public IP addresses

Azure portal → Public IP addresses → Export to CSV, which is the file this was built against. Or run the script: Resource Graph covers every subscription in one call instead of one blade per tenant.

Needs Install-Module Az.ResourceGraph and Connect-AzAccount. Reader on the subscriptions is enough — no app registration.
Load either file, or both. Both together is what produces the coverage answer.
