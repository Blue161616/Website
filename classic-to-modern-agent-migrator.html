Classic → Modern Agent Migrator

Copy classic agent service principals into Entra Agent ID blueprint identities

Discovers classic agents (agents created as service principals — e.g. classic Copilot Studio agents) in your Microsoft Entra tenant and recreates them as modern agents on the Agent Identity Blueprint platform. Because in-place migration isn't supported, each classic agent is copied to a new agent identity — by default named "<original name> (new)". Runs entirely in your browser using your own delegated access.

Pre-filled with this tool's published multi-tenant app. Override it only if you run your own registration — an override is stored locally in your browser.

How a copy is made: for each selected classic agent, a new agent identity is created from the chosen blueprint via POST /servicePrincipals/microsoft.graph.agentIdentity with the copy's display name, the blueprint's appId, and the sponsor. This is a fresh identity — permissions, connectors and configuration are not carried over and must be re-granted to the modern agent (least-privilege is recommended).
