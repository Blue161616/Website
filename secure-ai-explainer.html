01 · Why it exists

Agents are the new insider risk

Agent adoption is moving faster than organisations can track it. Agents run in the cloud and on employee devices with real access to business data. Even an agent doing an approved task can turn risky halfway through.

Observe everything

IT needs to know which agents run, who owns them and what they can reach, across cloud platforms and local devices.

Contain what the agent can do

An agent shouldn't inherit all of its user's standing access. It should get only what the task needs, for as long as the task runs.

Operate at machine speed

Security teams can't investigate thousands of agents one by one. Protection has to adapt as fast as the agents act.

“

Don't ask a model to be its own security authority. Keep the controls over access, actions and whether it may keep running outside the model, where it can't bypass them.

The design principle behind Secure AI: the most trustworthy agentic system is the one designed to trust the model least.

04 · Dynamic agent risk

One risk level per agent, updated as it acts

Dynamic agent risk fuses runtime signals, exposure and blast radius from across the Microsoft stack into one level that IT and security both see, in the Microsoft 365 admin center, Entra, Defender, Purview, Intune and Perception. Dynamic Conditional Access then responds in steps, not with a kill switch.

06 · Layers of defence for local agents

Contain agents across endpoint, runtime and network

A local agent such as Claude Code or GitHub Copilot CLI gets its own Agent ID. Then every layer can act on the agent alone: Defender on the endpoint, Windows MXC execution containers at runtime, Entra GSA on the network and Purview DLP on the data path. Send the agent a request.

# local agent terminal

Agent ID and MXC are separate layers; controls also work without MXC. Attribution is best effort and user-level controls still cover what can't be attributed, so don't promise perfect isolation.

07 · Project Perception

A team of Guardian agents

Perception adds a risk-based view of your agents, a portfolio of purpose-built playbooks and Guardian agents that carry them out. It builds on Agent 365, ME5 and Entra Suite: those tools are the sensors and actuators, Perception coordinates them.
